Portfolio rewrite review

An inventory of the current app, a proposed information architecture, three design directions with desktop, mobile and compact-landscape prototypes, an AG-UI design for Ask, and a phased roadmap. Nothing in the application code has changed. Implementation starts after you approve the decisions below.

Selected direction: Programme

A deliberate synthesis of the three explorations, built on the final foundation: shadcn/ui, Tailwind v4 and Base UI. The site reads like a well-run programme, with a clear plan, evidence of delivery and honest status. The refinement canvas validates the shell, Home, a case study, Ask and its states, mobile, compact landscape and the token sheet.

DD-1 · accepted

Programme: the Programme Line, ledger structure, declarative voice, and one status language for content and AI

From B it keeps the career timeline, project cards and transparent tool activity, without the dark developer-tool look. From A it keeps serif long-form, ledger rules and citation-first answers, without the paper-and-terracotta palette. From C it keeps the voice and the portrait as identity, without the colour blocks or the floating pill. Fonts: Bricolage Grotesque, Newsreader, JetBrains Mono. One cobalt accent for action; amber only for "in flight".

What the inventory found

Full tables in 01-inventory.md.

  1. 1The AI knows nothing about you. The Copilot bubble has no actions and no context, and it sits inside the fixed footer.
  2. 2Three navigation implementations totalling about 3,700 lines. Five nav paths (/experience, /projects…) have no route.
  3. 3Career data exists three times (summary, experience, timeline). The search index is placeholder text (“XYZ University”).
  4. 4About 60 grid layouts are silently broken. MUI 7 drops the legacy Grid item xs props.
  5. 5Duplicate routes for /auth-callback and /auth-debug. Auth callback paths are a contract with the auth server and must not move.

Information architecture

Home makes the case in brief; five sections hold the evidence; Ask is a destination of its own, not a widget. Full route migration map in 02-information-architecture.md.

Primary nav

Work · Experience · Writing · Knowledge · About · Ask · ⌘K · Contact

Key moves

/works → /work, /blogs → /writing, /credits → /colophon, /profile → /account, new /experience and /ask. Every old URL redirects.

Ask leaves the footer

Ask gets its own route, a nav item and “Ask about this” on every page. The footer becomes static, which frees the vertical space compact landscape needs.

One content layer

Typed records feed the pages, ⌘K search and the agent's tools. The agent only sees what the site publishes.

Architecture diagrams

Interactive diagrams: pan, zoom, search and trace. They passed Archify's automated layout checks but haven't been reviewed visually in a browser.
